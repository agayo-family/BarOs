# WorkHub PWA

Персональный рабочий штаб: проекты, квесты, фокус, финансы, аналитика и ачивки.

## Важно о данных
- Данные хранятся локально в браузере (localStorage).
- Экспорт/импорт JSON доступен в Настройках.
- Проценты проектов из исходного состояния помечены по уровню достоверности: подтверждённый / оценочный / оценка пользователя.
- 2GIS установлен на 38% как середина пользовательского диапазона 35–40%.
- Финансовая история неполная: показатель «погашено» содержит только суммы, которые были подтверждены и внесены в WorkHub.

## Запуск локально
Откройте папку через любой статический HTTP-сервер, например:
```bash
python -m http.server 8080 -d workhub
```
Затем откройте http://localhost:8080.

## PWA
При размещении по HTTPS приложение можно установить на телефон/ПК через браузер.

## Ветка
Собрано в ветке `workhub-pwa`, чтобы не менять основной BarOS.
