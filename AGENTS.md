# BarOS learning content

For new BarOS courses with a 30-question test, prepare at least 300 questions.
Aim for 320–500 when the material supports that many. For a different test size,
aim for a bank at least ten times the test length, within the import limits.

Cover every lesson. Mix knowledge, interpretation, decisions in realistic
scenarios, and calculations where the topic calls for them. Use plausible
distractors and an unambiguous answer with an explanation. Check exact and
near duplicates. Changing names, numbers, or the order of choices alone does
not add a new skill. Document any shortfall if the source needs more material.

Keep fixed and written assessments separately scored. Create a reusable
practice bank alongside them when repeated practice is needed. Preserve the
existing approval flow for catalog revisions and verify exam rotation on the
published revision in a test environment.
