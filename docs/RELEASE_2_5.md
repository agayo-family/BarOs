# Аудит BarOS 2.5 — Qwen и личный питомец-наставник

Дата: 9 октября 2026. Обновление продолжает опубликованную 2.4.1. Питомцы, игры, профиль, достижения, опыт, золото и график смен сохраняются.

## Реализовано

| Область | Результат |
|---|---|
| Провайдеры | Qwen3.5 Flash для бесед, Qwen3.5 Plus для документов/фото/методиста; отдельные адаптеры и независимые переключатели методиста и наставника |
| Резерв | Явно включаемый Yandex AI Studio; AliceAI Flash для беседы, мультимодальный Qwen3.6 35B для документов; только разрешённые официальные endpoints |
| Питомец | Все 15 существующих имён, легенд и характеров используются в prompt; индивидуальная базовая помощь без API; выбранный питомец и оформление берутся из профиля |
| Контекст | Доступная сотруднику публикация, выбранный урок, собственный завершённый тест или отвеченное игровое задание; точные проверяемые цитаты |
| Память | Текущие доступные изученные темы, недавние попытки и типичные ошибки, сохранённые опыт и достижения; своя история, новые ветки при смене питомца/публикации |
| Методист | Распознавание ограниченных и очищенных изображений, контрольные точки по страницам, теория, программа и банк; карточки и шесть игр из проверенного банка без дополнительных AI-вызовов |
| Экономика | Native USD/RUB журнал, расчёт по usage, предварительный резерв, глобальные/сотрудник/заведение/задача лимиты; timeout сохраняет неподтверждённый резерв |
| Доступ | Изоляция заведений, проверка должностей/публикаций, CSRF, блокировка наставника во время итогового теста, серверный контекст вместо доверия браузеру |
| Надёжность | Идентификатор сообщения и хэш запроса, защита от двойного клика, восстановление сохранённого ответа без нового вызова, обработка прерванных сообщений |
| Интерфейс | Вкладка «Мой наставник», переход из ошибок игры/теста и урока, цитаты, память, индикатор ожидания; адаптивная сетка и reduced-motion |

## Автоматические проверки

- **60 серверных тестов** прошли: 48 существующих и 12 сценариев новой интеграции. Проверены идентичность питомца, личная история, смена редакции, типичные ошибки, чужие заведения/попытки, CSRF, права ролей и отсутствие дополнительных наград за беседу.
- Провайдерные тесты проверяют тело запроса Flash/Plus, JSON-формат, отключение thinking, проверку цитат/чисел, расчёт токенов, бюджеты до вызова, 401 без скрытого резерва, timeout с явно включённым Yandex и раздельные USD/RUB.
- Реальное создание/чтение DOCX и JPEG проверено локально. JPEG 2400×1800 уменьшается до максимум 1600; фотографии внутри Word обнаруживаются отдельно, ручная проверка текста отменяет повторное AI-распознавание. Ответ распознавания Plus в тестах **имитируется**, как и ответы для создания черновика.
- Полный путь vision → теория → подтверждённый вопрос → частичный неопубликованный черновик с программой проверен с тестовым ответом API. При нехватке фактов банк сохраняется для проверки, а не заполняется выдуманными вопросами.
- **261 реальный HTTP-запрос к локальному API + DOM**: обучение/должности/регистрация/карточки/темы/PWA/контакты/refresh — 84; смены, расчёты, часовые пояса и права — 47; шесть игр/сложность/профиль/питомцы/магазин/наставник — 130.
- UI наставника проверен с настоящим локальным сервером: имя выбранного питомца, контекст завершённой игры, память ошибок, безопасный вывод текста, цитата, двойная отправка и потерянный ответ после серверного сохранения. «Обновить» не отправляет новое сообщение.
- Компиляция Python, синтаксис всех browser JS-модулей и `git diff --check` прошли. Эти проверки и API/DOM-аудиты включены в GitHub CI.

Ошибки, найденные проверками, исправлены до публикации: неверная ссылка на курс в игровом разборе, очистка поля после восстановления потерянного ответа, завершение старого pending-сообщения, отрицательные query-параметры, ошибочная конфигурация провайдера, синхронизация программы с редактором и контроль версии файла при повторном OCR.

## Изменения данных

Добавляются только новые таблицы `v2_ai_requests`, `v2_mentor_threads`, `v2_mentor_turns`, `v2_course_programs` через существующий additive bootstrap. Старые таблицы питомцев/прогресса/игр/попыток/смен/AIUsage не удаляются и не переименовываются. Новые завершённые тесты включают идентификаторы для перехода к наставнику; прежние сохранённые результаты продолжают отображаться.

Ключей нет в клиентском коде или API-ответах. Беседы сохраняются на сервере в аккаунте пользователя; модель получает учебный контекст и ограниченную историю. Используется внешний провайдер, поэтому управляющий должен учитывать передачу выбранного материала при решении, какие файлы разрешены для AI.

## Практические пределы проверки

Платные ключи Qwen/Yandex не были предоставлены и не активировались этим обновлением. **Реальная доступность аккаунта, оплата, качество русского наставника, точность распознавания конкретного меню и задержка внешнего API не подтверждены тестами с имитацией.** Для этого нужен пробный запуск из инструкции с реальными ключами и проверкой Billing.

Сервер проверяет допустимый контекст, точность цитат и чисел, но не может доказать правильность каждого пересказа модели. Распознанный текст, теория и ответы требуют проверки управляющим перед публикацией. При недоступности или отклонении AI-ответа используется исходный проверенный фрагмент вместо новых догадок.

DOM-аудит не измеряет пиксели и работу экранной клавиатуры на физическом телефоне. CSS содержит адаптивные правила, перенос длинных строк, поля с читаемым размером и reduced-motion; реальные iOS/Android/PWA и узкие экраны отмечены отдельными пунктами ручного чек-листа.

Нагрузка на Render не была повторно измерена с реальными AI-вызовами. Предыдущие измерения и предположения в [аудите 2.4](RELEASE_2_4.md) не следует выдавать за гарантированное число пользователей новой версии. Общий worker по-прежнему выполняет одну задачу генерации за раз; общение использует асинхронный HTTP и освобождает DB-сессию перед ожиданием провайдера. Для коммерческой нагрузки нужны оплаченная PostgreSQL, измерение задержек/CPU/памяти и отдельное планирование worker/очереди.

## Что проверить пользователю

[Полная инструкция API, стоимость и ручной чек-лист](QWEN_MENTOR_SETUP.md). Сначала настроить Qwen в Render, проверить одно сообщение и одну фотографию, сверить токены и факты. Только затем включать резерв и расширять лимиты.

Бесплатная PostgreSQL текущего стенда истекает **28 октября 2026 в 10:44 МСК**. Продление web service не продлевает базу автоматически. Подписки BarOS по-прежнему управляются владельцем; автоматический приём денег от клиентов не добавлен этим этапом.
