# Восстановление входа после временной недоступности

2 ноября 2026 года, московское время. На снимке пользователя отображалась запасная страница service worker «Вы вне сети». Прямые запросы к корню и /health также не дождались ответа. В журнале приложения после остановки по завершении простоя не было нового успешного запуска. Сама страница не повторяла попытку и ошибочно называла любую недоступность сайта отсутствием интернета у пользователя.

## Немедленное восстановление

Текущая проверенная версия повторно развёрнута с неизменными настройками. Развёртывание `dep-dbjrfr942hec73dsc1e0` коммита `b85454e64d6f0e645019e60a26aad75b8f7ccd58` стало `live` 2 ноября в 01:08 МСК. После обновления вкладки /health вернул `status: ok`, версию 2.11.0; страница входа загрузилась. Восстановление не заменяло БД или секреты доступа.

## Исправление

- Запасная страница сообщает о недоступности сайта без утверждения, что у пользователя нет интернета.
- Страница автоматически повторяет GET-навигацию через 8 секунд и сохраняет исходный адрес с параметрами. Есть ручная кнопка повторения. Скрипты для восстановления не нужны.
- Запасной документ возвращается при сетевой ошибке и HTTP 5xx, имеет статус 503, `Cache-Control: no-store`, `Retry-After: 8` и отдельный маркер `X-BarOS-Recovery`.
- Успешные страницы и HTTP 4xx сохраняются. API, /health, запросы записи и другие источники не перехватываются. Ответы теста и вход не переотправляются.
- Обновлена версия статического кеша. Пользовательские API-ответы, сеансы и учебное содержание в него не добавляются.

## Проверка

Проверен коммит `24fbe068963141bc609bc7aa2abe38a69efe4c53`, дерево `a85f4a9c4beb9c8a2b7ec5c6518f579319d81c28`. [CI № 93](https://github.com/agayo-family/BarOs/actions/runs/41355882581) завершился успешно:

- Два прохода Chromium по 890 состояний каждый: роли, 36 курсов, ширины 360/390/768/1440 и обе темы. В обоих проходах нет ошибок браузера, неожиданных HTTP 5xx и обнаруженных нарушений геометрии.
- В обоих проходах получен `RECONNECT PASS`: настоящий service worker вернул запасной документ после отключения сети, затем страница сама загрузилась при возвращении связи с сохранением исходного адреса.
- Серверный набор из 147 тестов завершился успешно: 145 выполнено, два теста только для PostgreSQL пропущены в этом наборе. Отдельно прошли 63 проверки PostgreSQL и девять наборов API/DOM.
- Полное восстановление временной БД подтвердило совпадение количества строк и хешей содержимого 50 таблиц.
- Проверки самого service worker прошли; проверка зависимостей не обнаружила известных уязвимостей.

Реальные браузерные сценарии используют только временные базы. В обоих проходах отключается сеть, проверяются текст и заголовки запасного документа, затем связь возвращается. Страница должна сама загрузить тот же адрес без явного вызова перезагрузки из теста. Плановый синтетический 503 проверяется отдельно и не считается ошибкой приложения; настоящие HTTP 5xx продолжают контролироваться.
