# BarOS 2.9.0 — редактор общей библиотеки и пересмотр тестов

36 курсов, 320 уроков, 1440 вопросов. Исправлены варианты ответов, зависимости вопросов от соседних условий, часть терминов и длинных формулировок. Уточнены классические рецепты по IBA и происхождение whey по FDA. Формальные метрики сохранены в `audit-2.9-curriculum.json`; они не доказывают качество профессиональной подготовки.

В общей библиотеке владелец открывает курс и выбирает **Редактировать курс и тест**. Доступны теория, вопросы, объяснения, правильные ответы, результаты курса и настройки. Сохранение записывает черновик в БД. Правки переживают перезапуск приложения. Включение для существующих и будущих заведений требует отдельного просмотра и подтверждения владельца. Утверждённые копии, локальные изменения заведений и старые прохождения сохраняются.

Редактор использует права владельца, CSRF и номер версии для защиты от устаревшего сохранения. Сохранение и включение используют одну блокировку каталога; устаревшее подтверждение не публикует новый незамеченный черновик. Для PostgreSQL добавлен отдельный конкурентный сценарий.

Отдельные письменные тесты и ручная проверка сохранены. Домашние задания внутрь общей теории не возвращались. Никаких новых вызовов ИИ и новых платных сервисов эта версия не включает.

## Проверки выпуска

Два полных аудита успешно завершены: в каждом 121 серверный тест, 41 дополнительная PostgreSQL-проверка, восемь API + DOM сценариев, 802 состояния Chromium, восстановление 47 таблиц тестовой БД. Подробный охват, источники результатов и ограничения: [AUDIT_2_9.md](AUDIT_2_9.md).

## Неустранённые условия коммерческого запуска

На 27 октября 2026 текущая база `baros-staging-db` доступна, план free, регион Frankfurt; истекает 28 октября 2026 в 10:44 МСК. Внешний доступ закрыт пустым allowlist. Полная копия рабочей базы в этом выпуске не получена: подключённый SQL-инструмент не имеет доступа. Тест восстановления синтетической базы не заменяет резервную копию рабочей.

Для российских клиентов с персональными данными нужна отдельно согласованная схема размещения и документов. Платный Render в Frankfurt сам по себе не решает локализацию. Бюджет, юридическое лицо, платёжный провайдер и production-провайдер пока не выбраны. Автоматический эквайринг не подключён; первый B2B-пилот можно оформлять договором и счётом после подготовки рабочей инфраструктуры.

Полноценного офлайн-обучения в PWA сейчас нет: кэшируются статические файлы, личные API требуют сети. Мобильное приложение и обещания SLA требуют отдельного объёма работ.
