# BarOS 2.10 — черновики, завершение обучения и аналитика

## Работа с обучением

Вместо страницы встроенной генерации открыт раздел «Черновики обучения». Управляющий выбирает файлы из «Материалов», выгружает извлечённый текст и образец JSON, готовит обучение вне платформы и импортирует результат. Импорт создаёт черновик. Публикация требует отдельной проверки человеком. Встроенные обращения к моделям выключены по умолчанию (`BAROS_AI_ENABLED=0`).

Курс и самостоятельный тест можно создать вручную. Итоговый тест связывается с курсом в редакторе. Курс без автотеста должен иметь отдельную опубликованную проверку для тех же должностей. Нельзя архивировать тест, необходимый действующему курсу. Уже начатые попытки сохраняют свои задания и рубрики.

Редактор курса восстанавливает несохранённую теорию и незавершённый вопрос из той же вкладки браузера. После восстановления требуется сохранить изменения на сервере. Результат курса учитывает теорию, автотест (если назначен) и связанную письменную проверку. Ожидание оценки не считается завершением.

## Аналитика управляющего

Открывается в «Отчётах». Шесть разделов: команда, курсы, вопросы, тесты и ситуации, динамика и попытки. Есть фильтры периода, дат по Москве, должности, сотрудника, курса или отдельного теста; архивные редакции и неактивные сотрудники включаются отдельно.

Готовность команды считается по текущим назначениям за всё время. Метрики попыток относятся к выбранному периоду. Первая, последняя и лучшая оценки усредняются по отдельным редакциям курса; изменение сравнивает только редакции с повторными попытками. Трудные вопросы считаются по последней попытке сотрудника в каждой редакции за период. При менее трёх наблюдениях показана отметка «Мало данных». Нулевое число наблюдений отображается как отсутствие данных, а не нулевой балл.

Очередь письменных работ показывает сданные работы независимо от периода, включая прежние редакции и архивные тесты, начиная с наиболее давних. Оценки сгруппированы по дате проверки. Редакции тестов и критериев разделены. Для диагностики без проходного порога нет статуса провала. Разделы выгружаются в CSV; значения защищены от выполнения формул.

## Эксплуатация

Новые таблицы создаются дополнительно. Учётные записи, меню, материалы, прежние попытки, действующее одобрение общей библиотеки и подключение PostgreSQL сохраняются. Обновление исходников общей библиотеки не включает новые редакции автоматически в заведениях: требуется прежнее отдельное подтверждение владельца.

Push-уведомления имеют состояние по каждому устройству и ограниченное число повторов временных ошибок. После успеха устройство повторно не отправляется обычной очередью; при аварии между отправкой провайдеру и фиксацией в БД повтор теоретически возможен. Для реальной доставки необходимы действующая подписка браузера и разрешение пользователя.

Проверки и результаты двух аудитов фиксируются в `AUDIT_2_10.md`. Тесты используют отдельные временные базы. Реальная база не используется для изменения тестовых данных.
