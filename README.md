# BarOS 2.7.0

BarOS — светлая premium-платформа обучения для баров и ресторанов: материалы заведения, теория, тесты, роли, должности, уведомления и аналитика в одном адаптивном PWA.

## Общая библиотека и подключение заведений

В кабинете владельца откройте `/app/catalog`: 18 оригинальных курсов для барменов, официантов, администраторов, кальянщиков, поваров и клининг-мастеров. В каждом — четыре урока, 12 вопросов и две письменные ситуации без вариантов ответа с ручной проверкой управляющим. Просмотр доступен до общего включения. Новая установка и обновление приложения не утверждают курсы автоматически.

После прочтения владелец отдельно нажимает «Включить во всех существующих и новых заведениях» и подтверждает редакцию. Копии заведений самостоятельны; повторное включение не перезаписывает правки, архив и результаты. При создании заведения используется сохранённая утверждённая редакция. Остановка автодобавления сохраняет уже созданные материалы.

`/app/onboarding` показывает управляющих, сотрудников, материалы и опубликованные курсы каждого заведения. Персональное меню загружается отдельно. AI для библиотеки, подключения и письменной проверки не вызывается. Управляющий видит очередь ожидающих проверки работ в «Тесты и ситуации».

## Что уже работает

- владелец платформы: заведения, тариф/статус/лимиты, удалённый доступ, одноразовые ссылки управляющих и журнал действий;
- управляющий: команда, несколько должностей сотрудника, приглашение по коду, интервью о заведении, материалы, черновики курсов, публикация и отчёты;
- сотрудник: самостоятельная регистрация по коду, теория перед тестом, случайная выборка вопросов, перемешанные ответы, таймер, попытки, баллы, разбор ошибок и история;
- загрузка TXT/MD/CSV/TSV/PDF/DOCX/XLSX/PNG/JPG/WebP до 15 МБ с извлечением текста и OCR;
- бесплатный AI через OpenRouter (`openrouter/free`): пошаговая генерация теории и банка по объёму источника либо выбранной цели до 400 вопросов, source-grounding, защита от повторов, сохранение прогресса и повтор после сбоя;
- in-app и Web Push уведомления о новом курсе, дедлайне и просрочке;
- PWA-манифест, service worker, responsive-интерфейс для телефонов, планшетов и мониторов.
- шесть учебных игр с тремя уровнями сложности, лишними словами и объяснением ошибок;
- профиль с аватаром, достижениями, опытом, золотом, 15 пиксельными питомцами и магазином украшений;
- прямой OpenAI API с явным включением, строгим форматом ответа, учётом токенов и бюджетами.
- адаптеры Qwen3.5 Flash для питомца-наставника и Qwen3.5 Plus для документов, фото и программы обучения;
- личная беседа с выбранным питомцем, история, подтверждённая память об учёбе и ошибки из завершённых заданий;
- отдельные лимиты сообщений и расходов по сотруднику/заведению, журнал USD/RUB, резерв Yandex с явным включением.
- импорт готового `.baros.json`: полный курс с теорией и банком для теста, карточек и игр либо отдельный письменный тест с ручной проверкой;
- последовательные разделы письменного теста, сохранение ответов, таймер, рубрики и явное ограничение балла при нарушении brief.
- полное редактирование импортированного теста: настройки, добавление, удаление, копирование и порядок разделов и заданий, ответы и рубрики; отмена правок и сохранение прежних работ участников.
- отметки связанных курсов после изменения исходного меню и отдельное подтверждение проверки перед публикацией;
- отчёт «Что повторить с командой»: конкретные вопросы и сотрудники по последней попытке текущей версии курса;
- последовательное сохранение обычного теста, восстановление после сетевой ошибки и закрытое редактирование во время сдачи.

AI всегда создаёт черновик. Управляющий обязан проверить факты, теорию и ответы перед публикацией.

Платные Qwen и Yandex выключены по умолчанию. Без ключей питомец показывает проверенные фрагменты уроков и сохранённый разбор заданий. API не вызывается при каждом действии в игре, карточке или обычном тесте. `AI_PROVIDER` выбирает методиста, `MENTOR_PROVIDER` — наставника; существующий OpenRouter/OpenAI остаётся доступен.

## Локальный запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # optional
uvicorn baros.main:app --reload --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000/first-run?token=<FIRST_RUN_TOKEN>` и создайте владельца. Для production задайте PostgreSQL, длинный `SESSION_SECRET`, `FIRST_RUN_TOKEN` и `COOKIE_SECURE=1`.

## Восстановление владельца

Если забыты логин и пароль, откройте `/owner-recovery`. В Render → `baros-staging` → Environment
скопируйте `FIRST_RUN_TOKEN` (случайный секрет длиной от 24 символов) и введите его **только на сайте**.
Если ключ отсутствует, слишком короткий или уже использован, задайте новый случайный ключ в Render
и сохраните с перезапуском сервиса. На странице восстановления задайте новый логин и пароль от 12 символов.
Ключ используется один раз; прежние сеансы владельца отзываются. Существующий аккаунт, заведения,
сотрудники и обучение сохраняются. Ключи и пароли не передавайте в чат и не включайте в URL.

## AI без платного fallback

```env
OPENROUTER_API_KEY=...
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_MODEL=openrouter/free
AI_ALLOW_PAID_FALLBACK=0
```

Платный fallback выключен по умолчанию. Лимиты `AI_DAILY_LIMIT`, `AI_GLOBAL_DAILY_LIMIT` и `AI_PROVIDER_DAILY_CALL_LIMIT` ограничивают расход и нагрузку.

## Деплой Render

`render.yaml` содержит web service и PostgreSQL. После создания сервиса добавьте секреты `FIRST_RUN_TOKEN` и `OPENROUTER_API_KEY` в Render Dashboard. Healthcheck: `/health`.

Загрузка хранится в PostgreSQL вместе с извлечённым текстом, поэтому перезапуск бесплатного инстанса не теряет исходник. Для больших production-файлов рекомендуется object storage и отдельный worker.
